# Benchmark artifacts

## `small-exact.json`

Generated by `scripts/generate_small_benchmarks.py`. Every expectation is an
exact rational number for the stated 21-point candidate grid and
strict-full-support action mesh of denominator 6. The payoff-range convention
uses fixed-`f` oracle information for every policy to isolate sampling and
continuation effects. An off-mesh comparator can beat the mesh optimum.

## `certified-score-synthetic.json`

Generated by `scripts/benchmark_certified_scores.py`. Four fixed-seed synthetic
populations have `N=1000`. The descending-uncertainty review count is exact;
randomized comparator summaries use 1,000 exponential-race permutations per
policy. Exponential races generate the exact Plackett--Luce order associated
with probability-proportional sampling without replacement.

These are mechanism stress tests. They are not client data, field validation,
regulatory evidence, or estimates of savings for any real audit population.
